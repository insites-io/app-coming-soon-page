## Overview

The Insites Coming Soon Page is designed to attract potential clients and provide them with a seamless experience. The page is responsive and optimized for various devices, ensuring that all users have access to our information.

<br>

## Features

- Responsive design
- Clean and modern UI
- Fast loading times
- Easy navigation

<br>

## Technologies Used

- **HTML5**
- **CSS3 (with Flexbox/Grid)**
- **JavaScript**
- **Liquid**: Templating language for dynamic content rendering.
- **Foundation Framework**: A responsive front-end framework for building responsive websites.
- **Insites Components**: Pre-built components that enhance UI/UX for the Insites brand.
- **GraphQL**: Used for querying and managing data, enabling efficient data retrieval and manipulation
